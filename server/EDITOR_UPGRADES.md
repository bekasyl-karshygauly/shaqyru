# Обновления редактора

Существующие дизайны, фото, анимации, музыка, личные ссылки, оплата и местные черновики сохранены.

## История изменений

Кнопки «Отменить» и «Повторить» находятся над редактором. Раскройте «История изменений», чтобы вернуться к конкретному состоянию. Серия ввода в одно поле объединяется в один шаг. После возврата назад новая правка создаёт новую ветку без старых повторов.

История сохраняется в IndexedDB отдельно для каждого местного черновика, до 30 состояний с ограничением размера. При крупных фотографиях число состояний сокращается. Очистка данных браузера удаляет историю. Она не синхронизируется между устройствами. Оплата, пароль, серверные версии, секреты владельца и закрытие доступа не откатываются. Ctrl/Cmd+Z и повтор работают вне полей ввода; внутри поля остаётся стандартная отмена текста.

## Личное обращение и ответы гостей

В разделе «Гостям» задайте обращение, например «Дорогие {name}!». На персональной ссылке вместо `{name}` подставляется имя гостя или пары из списка владельца. Общая ссылка остаётся без персонального обращения.

Включите нужные вопросы: дети, питание, трансфер. Число детей входит в общее количество участников и не может его превышать. При отказе дополнительные данные очищаются. Сводка и CSV включают новые ответы.

**Для хранения дополнительных ответов выполните `migrations/004_rsvp_details.sql` в SQL Editor существующего проекта Supabase.** Миграция добавляет поле `details`, сохраняя старые ответы. Перезапустите сервер либо подождите 10 секунд для обновления проверки доступности. `/api/config` возвращает `rsvpDetailsReady`. До подключения дополнительных полей обычный ответ гостя остаётся доступным; редактор показывает сообщение о неподключённом хранении, дополнительные вопросы гостям не показываются. Миграция в реальной базе автоматически не применялась.

## Видео

Раздел «Интро» → «Видео для Stories и мессенджеров»: выберите 8 или 12 секунд, при необходимости включите выбранную музыку и нажмите «Создать видео». После записи доступны проигрыватель и скачивание.

Это отдельная вертикальная композиция 720 × 1280 с фото, именами, датой, адресом и движением по мотивам выбранного интро; не запись всей HTML-страницы и не точная копия всех её эффектов. Браузер выбирает поддерживаемый MP4 либо WebM. Если мессенджер не принимает WebM, потребуется конвертация или браузер с поддержкой записи MP4. Во время записи держите вкладку открытой: при её скрытии запись отменяется. Камера и микрофон не используются. Внешние фото и музыка требуют разрешения CORS источника; при ошибке загрузите свой файл или отключите музыку. Отмена доступна во время подготовки и записи.

Использованы стандартные API: [MediaRecorder и проверка формата](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder/isTypeSupported_static), [запись потока Canvas](https://developer.mozilla.org/en-US/docs/Web/API/MediaStream_Recording_API), [аудиодорожка из Web Audio](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/createMediaStreamDestination).

## Совместная работа

В разделе «Программа» раскройте «Совместная работа», выберите просмотр или редактирование и создайте ссылку. Создание предварительно сохраняет приглашение на сервере. Ссылка действует 7 дней, максимум 10 активных ссылок; её можно отозвать. Передавайте её только выбранному человеку: доступ получает любой обладатель ссылки. Сервис сам не отправляет сообщений.

Партнёр открывает отдельную страницу `/collaborate.html`. Редактор может менять имена, организаторов, дату, время, место, адрес, текст, программу, обращение, дресс-код и пожелания по подаркам; рядом доступен предпросмотр. Владелец продолжает пользоваться полным редактором. Просмотр не разрешает сохранение даже прямым запросом API. Доступ не раскрывает токен владельца, список гостей, оплату, пароль и настройки совместного доступа. Срок и отзыв проверяются сервером на каждом запросе. Секрет ссылки хранится в базе только как SHA-256; в браузере передаётся в заголовке, а не query-параметре. Серверная проверка версий предотвращает перезапись одновременных правок.

При конфликте партнёр может скачать свои правки. Загрузка актуальной версии при несохранённых изменениях сначала предлагает файл восстановления через загрузку браузера. Совместная работа использует существующую таблицу приглашений и не требует облачного аккаунта или новой SQL-миграции; необходимы действующие серверные настройки Supabase.

## Проверка перед отправкой

Кнопка «Проверить приглашение» учитывает обязательные данные, адрес, часовой пояс и уже прошедшее время сегодня. Дополнительно отмечает отсутствие фото, неполные координаты, закрытый доступ и автоматическое закрытие раньше начала праздника. Замечания ведут к нужному полю и не блокируют сохранение.
