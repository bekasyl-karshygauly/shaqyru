# Проверка Telegram и адресов — 21.10.2026

Реализованы постоянные адреса по именам, совместимость прежних ссылок, QR и персональных гостей, безопасное подключение прежнего Telegram-бота через скрытый локальный ввод и проверка отправки из кабинета.

Проверено:

- 57 серверных и модульных тестов прошли. Дополнительно повторены 4 проверки QR/языков после расширения разрешённых адресов; QR декодируется без токена владельца.
- 10 браузерных сценариев заказа, кабинета и новых ссылок проверены. После исправления подготовки версии в новом тесте он повторно прошёл; сценарии реального рабочего процесса и прежних ручных ссылок сохранились. Два новых сценария затем прошли с дополнительной проверкой открытия по красивому адресу, промежуточного прогресса прокрутки, обратного направления, редактора гостей и QR.
- 108 проверок синтаксиса прошли.
- На реальном Supabase проверены RLS и отсутствие доступа anon/authenticated к выделению адреса. Временная транзакция от имени service_role подтвердила постоянство адреса и суффикс для совпадений; транзакция откатилась.
- В базе осталось 18 приглашений и 0 постоянных тестовых адресов. Содержимое существующих приглашений не менялось.
- Проверки Supabase advisors: для новой закрытой серверной таблицы ожидаемое информационное замечание RLS без публичных политик; публичные политики не добавлялись. Прежнее замечание Auth о защите скомпрометированных паролей и два прежних неиспользованных индекса не относятся к изменению.
- Обновлённый сервер работает на http://localhost:3108. Health и защищённые настройки кабинета отвечают 200; несуществующий красивый адрес — 404. Очередь доступна.

Ограничения: Telegram-токен и ID чата отсутствуют, PUBLIC_URL локальный. Реальные getMe/sendMessage и доставка на устройство не выполнялись. Браузерные тесты Telegram используют подменённые ответы, серверные — отдельную базу в памяти. Новые тесты выполнялись в Chromium с мобильной шириной экрана; физические iPhone/Android не проверялись.

Для реального подключения требуется локально ввести токен BotFather и подтвердить свой чат, затем перезапустить сервер. Автоматическая отправка заявок включится только после настройки публичного HTTPS-адреса. См. ORDER_NOTIFICATIONS.md.
