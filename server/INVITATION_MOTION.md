# Управление приглашением прокруткой

Гостевая страница `/i/:id` использует `public/invitation-scroll.js`.
Полный `/preview` подключает ту же систему по кнопке проверки открытия.
Встроенные предпросмотры заказов, сравнение и сохранение прокрутки сохраняются.

- Свайп вверх / колесо вниз открывает заставку. Обратное движение закрывает её.
- Остановка не запускает таймер завершения: сцена сохраняет свою позицию.
- Кнопка «Открыть» вызывает обычную плавную прокрутку браузера по этому же участку.
- «Пропустить» и Escape переходят к концу участка. Сцена остаётся для обратного хода.
- Снижение движения убирает автоматическое раскрытие и длинный участок прокрутки.
  Ручной тест варианта в редакторе по-прежнему можно запустить явно.
- Музыка, RSVP, языки, фотоистория, карты, печать и данные заказа не меняются.

## Владение анимацией

Исходные геометрия и keyframes всех вариантов остаются в `card.js`, `style.css`,
`opening-scenes.js/css`. Их новый необязательный параметр `controlled` позволяет
создать ту же сцену без модального диалога, таймера удаления и автозапуска времени.
Редактор и демонстрация без этого параметра продолжают работать как раньше.

GSAP timeline меняет числовые часы; paused WAAPI animations получают currentTime.
Один ScrollTrigger `invitation-opening` связывает раскрытие и существующий вход
карточки. `invitation-depth` связывает повторяющиеся эффекты карточки и глубину со
всей страницей. `invitation-section-N` отвечает за каждый соответствующий раздел.
Все используют scrub:true, явные начальные значения и обратимые диапазоны.

Параллакс использует индивидуальный CSS translate через `--scroll-depth`,
не перезаписывая transform входа. Вращение портальных колец использует rotate,
оставляя transform исходному расширению. Плавающий орнамент вложен в отдельный
span, поэтому его движение и вход не спорят за transform. Нового декора нет.

Нативный sticky удерживает карточку на коротком участке открытия. Перехвата
touch/wheel, preventDefault для прокрутки, Lenis, принудительного snap и отдельных
requestAnimationFrame циклов движения нет. ResizeObserver, загрузка фото и шрифтов
обновляют расчёты. Размер участка берётся из viewport; ignoreMobileResize помогает
избегать лишнего пересчёта при движении мобильной адресной строки.

GSAP/ScrollTrigger 3.15.0 включены локально в `public/vendor`; CDN не требуется.
Исходники пакета закреплены в package-lock.json; уведомления лицензии сохранены.

## Проверка

`npm run test:motion` — новый набор и регрессии редактора/демо.
`SCROLL_TEST_URL` позволяет использовать уже запущенный локальный тестовый сервер;
без этой переменной Playwright запускает сервер на 3107 самостоятельно.
Основные API гостевых данных в этих проверках подменяются фикстурами;
реальные приглашения и Supabase не изменяются.

Реальные iPhone/Android и Safari требуют отдельной проверки на устройствах.
